# Skydive CLI issues

This repository tracks bugs and feature requests for the [Skydive CLI](https://skydive.com/cli).

- [Report a CLI bug](https://github.com/Create-Inc/skydive-cli/issues/new?template=bug-report.yml)
- [Request a CLI feature](https://github.com/Create-Inc/skydive-cli/issues/new?template=feature-request.yml)
- [Read the CLI documentation](https://skydive.com/docs/cli/overview)

The CLI source is maintained in a private repository. Pull requests are not accepted here.

When possible, run `skydive logs export` after a bug occurs. Attach the exported archive to your report. Review the archive before upload if the session contains sensitive work.
